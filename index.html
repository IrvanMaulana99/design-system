📋 Usage Guide

Copy file HTML ini, pisahkan bagian <style> ke file CSS, langsung pakai class-nya. Tidak butuh framework, build tool, atau npm install.

⚡
Quick Start — 3 Langkah
Link font Google → link CSS → pakai class. Zero dependency, pure CSS custom properties.
<!-- 1. Google Fonts di <head> --> <link href="https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400;9..40,500;9..40,700&family=DM+Mono:wght@400;500&family=Scheherazade+New:wght@400;700&display=swap" rel="stylesheet"> <!-- 2. CSS --> <link rel="stylesheet" href="irvan-design-system.css"> <!-- 3. Pakai langsung --> <button class="btn btn-primary btn-md">Simpan</button> <div class="card card-interactive">...</div> <span class="badge badge-accent badge-dot">Online</span>
/* Ganti tema — Purple (default) → Blue */ /* Cara 1: scope ke seluruh halaman */ <body class="theme-blue"> /* Cara 2: scope ke satu section saja */ <section class="theme-blue"> <button class="btn btn-primary btn-md">Biru</button> </section> /* Cara 3: custom accent warna lain */ :root { --accent: #059669; /* hijau */ --accent-hover: #047857; --accent-deep: #065f46; --accent-50: #ecfdf5; --accent-100: #d1fae5; --accent-ring: rgba(5,150,105,0.22); --accent-glow: rgba(5,150,105,0.28); }
✅ Konvensi Class
  • btn + variant + size
  • badge + warna + modifier
  • card + modifier opsional
  • text-* tipografi
  • grid-N layout kolom
  • theme-blue accent switcher
♿ Accessibility Checklist
  • Semua teks body: contrast ≥ 4.5:1
  • Focus ring: 3px visible keyboard nav
  • Touch target: min-height ≥ 44px
  • Animasi: respek prefers-reduced-motion
  • Form: label + id selalu terhubung
  • Icon-only btn: wajib aria-label
